## 專案概述

協助臨床研究者在正式分析前快速檢視數據品質，包含異常值偵測、缺失值分佈分析等功能，降低因資料問題導致的分析偏誤。

## 主要功能

- **數據品質診斷**：自動偵測異常值、極端值與格式不一致的欄位
- **缺失值分析**：視覺化缺失模式，協助判斷缺失機制（MCAR / MAR / MNAR）
- **快速摘要統計**：一鍵產生描述統計報表，支援連續與類別變數
- **純前端部署**：資料不上傳伺服器，保護受試者隱私

## Overview

A browser-based tool designed to help clinical researchers inspect data quality before formal analysis — covering outlier detection, missing data distribution, and basic descriptive statistics.

## Key Features

- **Data quality diagnostics**: Automatically flags outliers, extreme values, and inconsistent field formats
- **Missing data analysis**: Visualizes missing patterns to assist in identifying the missing mechanism (MCAR / MAR / MNAR)
- **Quick summary statistics**: One-click descriptive reports for both continuous and categorical variables
- **Frontend-only**: Data never leaves the browser, protecting participant privacy
