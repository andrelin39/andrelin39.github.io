## 專案概述

純前端的便利貼應用，在瀏覽器中即可使用，不需任何後端或帳號。以 `localStorage` 儲存資料，關閉視窗後資料仍保留。

## 主要功能

- **Markdown 渲染**：便利貼內文支援 Markdown 語法（標題、列表、粗體等）
- **標籤分類**：為每張便利貼加上自訂標籤，快速篩選分類
- **本地儲存**：資料存於瀏覽器 `localStorage`，無需登入、無隱私顧慮
- **零後端**：純 HTML + CSS + JavaScript，可直接部署於 GitHub Pages

## Overview

A fully client-side sticky notes app that runs in the browser — no backend, no login required. Data is persisted via `localStorage`, so notes survive page reloads and browser restarts.

## Key Features

- **Markdown rendering**: Note content supports Markdown syntax (headings, lists, bold, etc.)
- **Tag filtering**: Assign custom tags to notes for quick categorization and filtering
- **Local storage**: Data stored in the browser's `localStorage` — no account needed, no privacy concerns
- **Zero backend**: Pure HTML + CSS + JavaScript, deployable directly on GitHub Pages
